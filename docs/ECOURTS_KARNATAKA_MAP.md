- Only **case types** vary per establishment.
- The Case Number, Case Type and Caveat case-type lists are identical.
- Acts, police stations, judge postings, cause-list courts and subordinate courts are set **per court complex**.
- Check across the state: for 166 complexes with two or more establishments, the acts list of the last establishment equalled the first in every case.

- 88 complexes have no subordinate courts; that is normal (only district-level courts hear appeals from subordinate courts).
- Court-complex values have the form `<complex>@<est,est,…>@<flag>`. Case-type values have the form `<type>^<est>`, and the same abbreviation can have a different type code in another establishment.
