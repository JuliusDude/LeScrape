# Update notes

Maintain `CHANGELOG.md` with each user-facing feature, behavior change, or bug fix. Include the note in the same commit as the change. Add a short bullet under **Unreleased** describing what changed for the user. Group related fixes into one entry and mention any migration or action the user needs to take.

When cutting a release, move its entries from **Unreleased** into a dated section, newest first. Use the actual version or tag when one exists. Keep earlier release notes intact unless correcting a factual error.
